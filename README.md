### Вопросы 
1. Чем final отличается от const в Dart?

final значение присваивается один раз при запуске.
const значение вычисляется на этапе компиляции и всегда неизменно.

2. Что означает String?

String строковый тип данных, хранит текст.

3. Чем Future отличается от обычного значения? Что означает await с точки зрения
потока выполнения?

Future объект для значения, доступного в будущем.await приостанавливает функцию, пока не придёт результат Future.

4. Зачем в Dart именованные конструкторы, если в C# есть перегрузка?

В Dart нет перегрузки конструкторов как в C#, поэтому используют именованные конструкторы для разных способов создания объекта.
